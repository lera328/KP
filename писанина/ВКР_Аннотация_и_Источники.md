# АННОТАЦИЯ

Выпускная квалификационная работа посвящена проектированию и реализации автоматизированной информационной системы для управления образовательным процессом детской школы программирования. Проведён анализ существующих CRM- и LMS-решений, сформулированы требования, спроектирована архитектура и база данных, реализовано веб-приложение на основе Django REST Framework и React. Реализованы подсистемы управления пользователями, расписанием и посещаемостью, отработками пропусков, финансами, а также генерация цифрового портфолио ученика и алгоритм аналитики риска оттока.

Пояснительная записка содержит 62 с., 24 рис., 1 табл., 20 источников.

# РЕФЕРАТ

Отчет 62 с., 3 гл., 24 рис., 1 табл., 20 источников.

ПРОГРАММНОЕ ОБЕСПЕЧЕНИЕ, АВТОМАТИЗАЦИЯ ОБРАЗОВАНИЯ, ПРОГРАММНАЯ ИНЖЕНЕРИЯ, CRM, LMS, WEB-ПРИЛОЖЕНИЕ, REST API, DJANGO, REACT, АНТИОТТОК-АНАЛИТИКА, ПОРТФОЛИО

Объект исследования — автоматизация процессов управления детской школой программирования.

Цель работы — проектирование и реализация автоматизированной системы управления образовательным процессом, финансами, коммуникациями и цифровым портфолио учеников детской школы программирования.

В процессе работы были проанализированы отечественные и зарубежные аналоги, сформулированы функциональные и нефункциональные требования, выбраны методологии и стандарты программной инженерии, разработан комплект архитектурных моделей, реализовано веб-приложение и выполнено тестирование.

В результате выполнения работы создана автоматизированная информационная система, включающая модули пользователей и ролей, учебного процесса, финансов и уведомлений, портфолио и проектной ленты, а также алгоритм расчёта рисков оттока учеников.

# ПЕРЕЧЕНЬ СОКРАЩЕНИЙ И ОБОЗНАЧЕНИЙ

В настоящей выпускной квалификационной работе применяют следующие сокращения и обозначения:

API — программный интерфейс прикладного программирования (Application Programming Interface)

CRM — система управления взаимоотношениями с клиентами (Customer Relationship Management)

DFD — диаграмма потоков данных (Data Flow Diagram)

DRF — Django REST Framework

HTML — язык гипертекстовой разметки (HyperText Markup Language)

HTTP — протокол передачи гипертекста (HyperText Transfer Protocol)

JSON — формат обмена данными (JavaScript Object Notation)

JWT — JSON Web Token

LMS — система управления обучением (Learning Management System)

ORM — объектно-реляционное отображение (Object-Relational Mapping)

PDF — формат электронных документов (Portable Document Format)

REST — архитектурный стиль взаимодействия распределённых приложений (Representational State Transfer)

SPA — одностраничное приложение (Single Page Application)

СУБД — система управления базами данных
