# Скриншоты для отчёта по практике

Сюда нужно положить четыре изображения (формат PNG, имена сохранить как ниже — на них ссылается `PRACTICE_REPORT.md`):

| Файл | Что снять |
| --- | --- |
| `01_bot_start_success.png` | Экран Telegram-бота `@kiber1One1_bot` сразу после привязки — сообщение «✅ Аккаунт … успешно привязан». |
| `02_makeup_notification.png` | Уведомление об отработке — либо у родителя (`✅ Отработка подтверждена …`), либо у преподавателя (`📅 Новая отработка в расписании …`). Можно собрать обе картинки в одну. |
| `03_ui_block.png` | Блок «Telegram-уведомления» из личного кабинета (вид с кнопками «Подключить / Отвязать / Отправить тестовое сообщение»). Снимать на сайте https://kiberone-school.duckdns.org/. |
| `04_notification_events.png` | Раздел админки Django: `/django-admin/notifications/notificationevent/` — таблица с колонками «event type», «status», «student», «parent», «created at». |

## Как получить скриншоты

1. **01:** в Telegram открыть чат с ботом, привязать аккаунт через кабинет (или повторить через `/start <новый_токен>` из админки) — сделать скриншот окна с приветствием.
2. **02:** в админке подтвердить отработку (или вручную перезапустить `notify_parents_about_makeup_approval(r)` через `manage.py shell`) — сделать скриншот пришедшего сообщения в Telegram.
3. **03:** залогиниться в кабинете, открыть главную, сделать скриншот блока «Telegram-уведомления» (например, через системную «Ножницы»/«Snipping Tool»).
4. **04:** зайти на `https://kiberone-school.duckdns.org/django-admin/notifications/notificationevent/`, сделать скриншот списка.

После того как файлы окажутся в этой папке, отчёт автоматически их подтянет (Markdown-предпросмотр в IDE и при экспорте в PDF).
