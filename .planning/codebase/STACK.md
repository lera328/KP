# Stack

- Languages: Python, JavaScript, JSX, HTML, CSS.
- Backend runtime: Python 3.11 (Docker base image: python:3.11-slim).
- Frontend runtime: Node.js 20 (Docker base image: node:20-alpine).
- Backend framework: Django 4.2.11.
- API framework: Django REST Framework 3.15.1.
- Auth library: djangorestframework-simplejwt 5.3.1.
- Database: PostgreSQL 14.
- DB driver: psycopg2-binary 2.9.9.
- Configuration: python-dotenv 1.0.1 for environment variables.
- Production app server dependency: gunicorn 21.2.0.
- Frontend framework: React 18.3.1.
- Frontend routing: react-router-dom 6.28.0.
- UI styling: Bootstrap 5.3.3.
- Frontend build tool: Vite 5.4.10 with @vitejs/plugin-react 4.3.2.
- Frontend uses browser fetch API and localStorage for API calls and token storage.
